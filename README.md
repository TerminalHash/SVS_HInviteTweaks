# SVS_HInviteTweaks
That plugin fixes issues with NPC action `ComeToMyRoomWithYouHVer` (id 96) aka home H-invite.  
In short, that command has impossible conditions for picking target and very low rates for picking that command, which is why it's almost never encountered.

Done with help of DeepSeek 4.1 Flash LLM.

### Conditions for target picking
- Normal, High and Very High virtues is requiring 20+ love points and be in love with target;
- Low virtue requires or 15+ love points, or 20+ friend points;
- Lowest virtue requires or 5+ love points, or 10+ friend points;
- Characters shouldn't be naked;
- H-compatible pair.
